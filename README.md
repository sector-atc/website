# SECTOR — website

Public project website, project status, and future download information.

## Status

Repository foundation only. No implementation, deployed service, released API, or usable dataset is provided yet. Work is coordinated through [main repository Issues](https://github.com/sector-atc/sector/issues) and organization Projects.

## Contribution scope

Open an issue in the main repository before proposing a new subsystem. Describe the intended behavior, validation method, and compatibility requirements. Keep reusable tooling here and application-specific code in the main monorepo.

## Data and rights

Submit only material you own or have explicit permission to publish. Every external asset or fixture needs its source, license, attribution, and redistribution terms. Do not commit proprietary navigation data, credentials, or live-network captures. Synthetic data must be marked synthetic.

## Independence

SECTOR is independent and is not affiliated with, endorsed by, or officially approved by VATSIM. It is not for real-world air traffic control.
